# 🐾 МурКотик — сайт випадкових котиків

Сайт українською для телефона, планшета та ПК. Генерує випадкові **реальні фото котів** через TheCatAPI та **песиків** через TheDogAPI. **Це не ШІ-генерація нових зображень.**

## Що вміє

- 🐈 Відразу показує випадкового котика. Кнопка **«Ще котика!»** змінює фото.
- 📥 **«Зберегти»** завантажує оригінальне фото на пристрій.
- 🔎 Натисни на велике фото — відкриється повноекранний перегляд.
- ＋/− або коліщатко миші — наблизити/віддалити; один палець — рухати збільшене фото; два пальці — змінювати масштаб.
- ◱ **«Для скріну»** ховає зайві елементи. Торкнися екрана, щоб повернути кнопки.
- ♥ Додавай котів до «Улюблених», а «Нещодавні» зберігають останні 18 фото. Дані зберігаються локально в браузері.
- Адаптивний дизайн для телефонів, зокрема невеликих екранів.
- Не потребує API-ключа, реєстрації користувачів, бази даних або платних бібліотек.

## Структура

```text
MurrCat/
├── index.html       # Розмітка сайту
├── dog.html         # Окрема сторінка песиків

├── package.json     # Команда npm start

├── .gitignore

```

## 1. Як запустити у Visual Studio Code

1. Установи **Node.js 20 або новіший** (краще LTS) з офіційного сайту nodejs.org.
2. Розпакуй ZIP. Відкрий **саме папку `MurrCat`** у VS Code через **File → Open Folder**.
3. У VS Code обери **Terminal → New Terminal**.
4. Перевір, чи працює Node: `node -v`.
5. Виконай:

   ```bash
   npm install
   npm start
   ```

6. Відкрий у браузері **http://localhost:3000**.
7. Щоб зупинити сайт: у терміналі натисни **Ctrl + C**.

> **Важливо:** не запускай `index.html` подвійним кліком чи через Live Server. Фото та кнопка завантаження працюють через `server.js`, тому сайт потрібно відкривати за `http://localhost:3000`.

## 2. Як викласти код на GitHub

Найпростіше через VS Code:

1. Зареєструйся на github.com та ввійди в GitHub у VS Code.
2. Перевір, щоб у VS Code відкрита папка `MurrCat` і файли лежали в корені папки.
3. Відкрий ліворуч **Source Control** (піктограма гілки).
4. Натисни **Initialize Repository** (якщо запропонує).
5. Натисни **+** біля Changes, щоб додати файли.
6. Напиши повідомлення коміту `First version of MurrCat` та натисни **Commit**.
7. Натисни **Publish Branch / Publish to GitHub**.
8. Вибери **Public repository** або **Private repository**. Підтвердь вікна авторизації.
9. Перевір на github.com, що репозиторій містить `server.js`, `index.html`, `package.json` та інші файли.

Альтернатива — створити порожній репозиторій на GitHub, а потім додати всі файли через **Add file → Upload files**. При цьому не завантажуй зовнішню папку, через яку файли опиняться на зайвому рівні вкладеності.

## 3. Як викласти на Render (безкоштовний план, якщо доступний)

1. Увійди на **https://dashboard.render.com** через GitHub або інший доступний спосіб.
2. Натисни **New → Web Service** (не **Static Site**, бо є Node.js-сервер).
3. Обери **Git Provider → GitHub**, авторизуй Render і дозволь доступ до репозиторію `MurrCat`.
4. Вибери репозиторій `MurrCat` і натисни **Connect**.
5. У параметрах указуй:
   - **Name:** `murrcat` (якщо зайнято, наприклад `murrcat-ua-2026`)
   - **Language / Runtime:** `Node`
   - **Branch:** `main`
   - **Root Directory:** залиш порожнім (якщо файли репозиторію лежать у корені)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`, **якщо цей варіант показує твій акаунт**
6. Натисни **Deploy Web Service** / **Create Web Service**.
7. Після успішного деплою Render покаже URL на кшталт `https://murrcat-ua-2026.onrender.com`. **Точна адреса буде іншою** — скопіюй ту, яку видав Render.
8. Відкрий URL із телефона. HTTPS працюватиме автоматично.

**Примітка:** можливості безкоштовних планів Render змінюються. Якщо доступний Free Web Service, сайт може тимчасово «засинати» під час бездіяльності, тому перше відкриття після паузи буває повільним. Якщо Render не показує Free, не підтверджуй платний тариф без потреби.

## 4. Як оновити сайт після змін

Зміни `style.css`, `index.html` або `script.js` у VS Code. У вкладці **Source Control** знову зроби **Commit** і **Sync Changes / Push**. Render із підключеним GitHub зазвичай автоматично запускає новий деплой для оновленої гілки.

## 5. Як перевірити на телефоні до Render

Якщо телефон і ПК в одному Wi-Fi, можна відкрити сайт за локальною IP-адресою ПК, наприклад `http://192.168.1.20:3000` (це лише приклад; реальну IP подивись через `ipconfig`). У Windows брандмауер може попросити дозволити Node.js доступ до приватної мережі.

## 6. Поширені питання

- **Фото не завантажуються?** Перевір інтернет, чи працює `npm start`, і спробуй «Ще котика!». TheCatAPI — зовнішній сервіс; якщо він недоступний, зображення не завантажаться.
- **Помилка `node` або `npm` не знайдено?** Установи Node.js LTS та перезапусти VS Code.
- **Не працює кнопка «Зберегти»?** Відкривай сайт через `npm start` або опублікований Render Web Service, а не через `file://` або Live Server. На iPhone браузер може запропонувати збереження через стандартне меню завантажень.
- **Чи потрібен платний API?** Ні, для невеликого особистого сайту зазвичай достатньо публічного TheCatAPI без ключа. У зовнішнього сервісу можуть бути ліміти.
- **Чому фото повторюються?** API вибирає їх випадково; іноді випадковий вибір може збігтися.

Зроблено для зручної роботи на телефоні. 🐱

## 7. Нова сторінка песиків 🐶

- На головній `/` — котики, на `/dog.html` — песики.
- Перемикач сторінок знаходиться зверху на кожній сторінці.
- Песики отримуються з **https://api.thedogapi.com/v1/images/search**.
- У них незалежні «Улюблені» та «Нещодавні». Є всі функції котячої сторінки.
- Завантаження й перегляд фото песиків працює через `/api/dog-photo/:id` на нашому Node.js-сервері.

### Як оновити вже опублікований сайт без нового Render

1. Розпакуй нову версію архіву. Відкрий `MurrCat_With_Dogs` у VS Code.
2. Відкрий **github.com/MrWir4uk/MurrCat** (або свій репозиторій) → **Add file → Upload files**.
3. Завантаж усі файли **зсередини** папки `MurrCat_With_Dogs`, а не саму папку. Для наявних файлів підтвердь заміну через Commit changes.
4. Переконайся, що в корені репозиторію видно **`dog.html`**, **`dog.js`** і оновлені **`server.js`**, **`style.css`**, **`index.html`**. Стара сторінка котиків залишається.
5. Якщо Render увімкнув **Auto-Deploy**, то після коміту в гілку `main` новий деплой запуститься сам. Якщо ні — у Render → сервіс → **Manual Deploy → Deploy latest commit**.
6. Відкрий свій сайт, натисни **🐶 Песики** або додай `/dog.html` до URL.

**Порада:** якщо використовується локальний Git у VS Code замість завантаження через браузер, роби `git add .`, `git commit -m "Add dogs page"`, `git push origin main` (за умови, що локальна папка вже прив'язана до потрібного репозиторію). Не створюй другий сайт на Render.
